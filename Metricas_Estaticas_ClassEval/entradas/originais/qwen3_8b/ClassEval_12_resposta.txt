To address the problem, we need to implement two key methods for a game of Blackjack: `calculate_hand_value` and `check_winner`. These methods help determine the score of a player's and the dealer's hand and determine the winner of a round.

---

### ✅ 1. `calculate_hand_value(hand)`

This method calculates the total value of a hand, accounting for:

- **Face cards** (`J`, `Q`, `K`) → each worth 10
- **Ace** (`A`) → can be 1 or 11, and we choose the value that maximizes the hand without busting
- **Number cards** (`2` to `10`) → worth their face value

We iterate over each card, sum up the base values, and then adjust for Aces to ensure the hand value doesn't exceed 21.

---

### ✅ 2. `check_winner(player_hand, dealer_hand)`

This method compares the values of both hands and determines the winner:

- If the player's hand value is greater than the dealer's, the player wins
- If the dealer's hand value is greater, the dealer wins
- If both values are equal, it's a **tie**, which is a valid game outcome

---

### 🧠 Final Code Implementation

```python
def calculate_hand_value(self, hand):
    """
    Calculate the total value of a hand, considering Ace as 1 or 11.
    """
    total = 0
    aces = 0

    for card in hand:
        rank = card[:-1]  # Remove suit (e.g., 'A', 'J', '5', '10')

        if rank == 'J' or rank == 'Q' or rank == 'K':
            total += 10
        elif rank == 'A':
            total += 11
            aces += 1
        else:
            total += int(rank)

    # Adjust Aces to 1 if total exceeds 21
    while total > 21 and aces > 0:
        total -= 10
        aces -= 1

    return total

def check_winner(self, player_hand, dealer_hand):
    """
    Determine the winner of a round based on hand values.
    Returns 'Player wins', 'Dealer wins', or 'Tie' if values are equal.
    """
    player_value = self.calculate_hand_value(player_hand)
    dealer_value = self.calculate_hand_value(dealer_hand)

    if player_value > dealer_value:
        return 'Player wins'
    elif player_value < dealer_value:
        return 'Dealer wins'
    else:
        return 'Tie'
```

- The `check_winner` method handles all possible outcomes: player wins, dealer wins, or a tie.
