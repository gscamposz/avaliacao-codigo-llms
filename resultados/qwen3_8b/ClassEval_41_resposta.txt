To determine the winner in a game like Gomoku (Five-in-a-Row), we need to check whether a player has five consecutive pieces in a straight line — either horizontally, vertically, or diagonally. The key is to implement a helper method that checks for this condition in a given direction, and then use it to scan the board for any such line.

Here's a well-structured and efficient implementation of the logic:

---

### ✅ Gomoku Game Logic with Win Detection

```python
class GomokuGame:
    def __init__(self, size=15):
        self.size = size
        self.board = [['' for _ in range(size)] for _ in range(size)]
    
    def place_piece(self, x, y, player):
        if self.board[x][y] == '':
            self.board[x][y] = player
            return self.check_winner(x, y, player)
        return False

    def check_winner(self, x, y, player):
        directions = [(0, 1), (1, 0), (1, 1), (1, -1)]
        for dx, dy in directions:
            if self._check_line(x, y, dx, dy, player):
                return player
        return None

    def _check_line(self, x, y, dx, dy, player):
        count = 1
        # Check in one direction
        for i in range(1, 5):
            nx = x + dx * i
            ny = y + dy * i
            if 0 <= nx < self.size and 0 <= ny < self.size and self.board[nx][ny] == player:
                count += 1
            else:
                break
        # Check in the opposite direction
        for i in range(1, 5):
            nx = x - dx * i
            ny = y - dy * i
            if 0 <= nx < self.size and 0 <= ny < self.size and self.board[nx][ny] == player:
                count += 1
            else:
                break
        return count >= 5
```

---

### 📌 Explanation

- **`place_piece(x, y, player)`**:
  - Places the player's symbol on the board at position `(x, y)` if the cell is empty.
  - After placing, it checks for a win using the `check_winner()` method.

- **`check_winner(x, y, player)`**:
  - This method checks for a win by scanning in all four possible directions:
    - Horizontal
    - Vertical
    - Diagonal (top-left to bottom-right)
    - Diagonal (top-right to bottom-left)
  - It calls `_check_line()` for each direction.

- **`_check_line(x, y, dx, dy, player)`**:
  - This helper function checks for a sequence of 5 consecutive pieces in a given direction `(dx, dy)`.
  - It counts how many pieces are aligned in that direction, including both the direction and the opposite direction.
  - If the count is at least 5, it returns `True`, indicating a win.

---

### 🧠 Example Usage

```python
game = GomokuGame(size=15)
# Place pieces in a winning line
for i in range(5):
    game.place_piece(i, 5, 'X')  # Horizontal win
    game.place_piece(5, i, 'O')  # Vertical win
    game.place_piece(i, i, 'X')  # Diagonal win
    game.place_piece(i, 14 - i, 'O')  # Anti-diagonal win

# Check for win
winner = game.check_winner(4, 5, 'X')
print(f"Player {winner} wins horizontally!")
```

---

### 📌 Notes

- The game assumes a 15x15 board, but the size can be adjusted.
- The `place_piece()` method returns `True` if the move was valid and a win occurred, otherwise `False`.
- The win detection is efficient and only checks the relevant cells near the last move, reducing unnecessary computations.
