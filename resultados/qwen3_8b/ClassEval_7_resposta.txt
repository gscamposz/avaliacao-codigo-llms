Here's the complete and well-structured implementation of the `BalancedBrackets` class, which includes the required functionality to:

- **Clear** the input string by removing all non-bracket characters.
- **Check** whether the brackets in the cleared string are **balanced**.

---

### ✅ **Final Implementation**

```python
class BalancedBrackets:
    """
    This class is used to check if the brackets in a given string are balanced.
    """

    def __init__(self, expr):
        """
        Initializes the class with an expression.
        
        :param expr: The input string to be analyzed.
        """
        self.expr = expr
        self.left_brackets = ['(', '{', '[']
        self.right_brackets = [')', '}', ']']

    def clear_expr(self):
        """
        Clears the expression by removing all non-bracket characters.
        """
        self.expr = ''.join([c for c in self.expr if c in self.left_brackets or c in self.right_brackets])

    def check_balanced_brackets(self):
        """
        Checks if the brackets in the expression are balanced.
        
        :return: True if the brackets are balanced, False otherwise.
        """
        # First, clear the expression to get only brackets
        cleared_expr = ''.join([c for c in self.expr if c in self.left_brackets or c in self.right_brackets])

        stack = []
        for char in cleared_expr:
            if char in self.left_brackets:
                stack.append(char)
            else:
                if not stack:
                    return False
                top = stack.pop()
                if (top == '(' and char != ')') or (top == '{' and char != '}') or (top == '[' and char != ']'):
                    return False
        return len(stack) == 0
```

---

### 📌 **Explanation of Key Components**

1. **`__init__` Method**:
   - Initializes the `expr` string.
   - Defines `left_brackets` and `right_brackets` as lists of opening and closing brackets.

2. **`clear_expr` Method**:
   - Filters out all characters that are **not** opening or closing brackets.
   - Modifies the `expr` attribute to store only the relevant characters.

3. **`check_balanced_brackets` Method**:
   - Uses the cleared expression to avoid interference from non-bracket characters.
   - Uses a **stack** to match opening and closing brackets in a LIFO (Last In, First Out) manner.
   - Returns `True` if the stack is empty at the end (i.e., all brackets were matched), or `False` otherwise.

### 🧪 **Example Usage**

```python
# Example 1: Balanced brackets
bb = BalancedBrackets("a(b)c")
bb.clear_expr()
print(bb.check_balanced_brackets())  # Output: True

# Example 2: Unbalanced brackets
bb = BalancedBrackets("(()")
bb.clear_expr()
print(bb.check_balanced_brackets())  # Output: False

# Example 3: Nested brackets
bb = BalancedBrackets("({[]})")
bb.clear_expr()
print(bb.check_balanced_brackets())  # Output: True
```
